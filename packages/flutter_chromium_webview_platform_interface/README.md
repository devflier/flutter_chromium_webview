# flutter_chromium_webview_platform_interface

A common platform interface for the [flutter_chromium_webview](https://pub.dev/packages/flutter_chromium_webview) plugin.

This package allows platform-specific implementations of the lutter_chromium_webview plugin to use a common interface.

## Usage

This package is not intended to be used directly by application developers. Please see the [flutter_chromium_webview](https://pub.dev/packages/flutter_chromium_webview) package for usage instructions.
