# Deterministic native media fixture

`local-video.webm` is a synthetic four-second 640×360 / 30 fps VP9 test pattern,
75 KiB, without audio. It was generated locally with FFmpeg, not downloaded from
a remote media service. A looping HTML video exercises real Chromium demuxing,
decoding, media time, decoded/dropped frames, and accelerated rendering. It does
not test YouTube, audio output, 1080p/4K support, DRM or product memory budgets.

Reproduce (generated bytes can differ with encoder versions):

```sh
ffmpeg -f lavfi -i 'testsrc2=size=640x360:rate=30' -t 4 -an \
  -c:v libvpx-vp9 -b:v 160k local-video.webm
```

Frozen SHA-256: `324569821439b043ecc89ad32fd7fbd572936b80db95be05838f060411301884`.
Tests serve the bytes over loopback HTTP; no remote URL, forced GC or host
restart is used. Ownership and RSS assertions remain independent.

The local media profile uses `mediaPlaybackRequiresUserGesture: false`, matching
the YouTube adapter's private CEF playback context. Default/global contexts can
retain a renderer after browser closure; that distinct observation is preserved
in the validation report and is not silently accepted as private-session cleanup.
